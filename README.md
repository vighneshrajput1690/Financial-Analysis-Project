# FinancePro — Financial Analysis & Valuation

## 📊 Project Overview

**FinancePro** is an Excel-based financial analysis and valuation project developed to analyze a company's financial performance over a five-year period.

The project covers historical financial statements, growth analysis, profitability ratios, risk analysis, and peer-based valuation.

The objective of this project was to transform raw financial statement data into meaningful financial insights using Excel formulas and financial analysis techniques.

---

## 🎯 Objectives

* Analyze five years of financial performance
* Evaluate revenue and profit growth
* Calculate profitability ratios
* Analyze return on equity and capital employed
* Assess financial risk through debt-to-equity analysis
* Compare valuation metrics with industry peers
* Develop practical financial analysis skills using Microsoft Excel

---

## 📁 Workbook Structure

The Excel workbook contains four main sections:

### 1. Balance Sheet

Contains five years of balance sheet data including:

* Total Assets
* Liabilities
* Total Equity
* Capital Employed

### 2. Profit & Loss

Contains historical financial data for:

* Revenue
* Total Expenses
* Operating Profit
* Net Profit

### 3. Financial Analysis

The analysis section evaluates:

#### Growth

* Year-on-Year Revenue/Profit Growth

#### Profitability

* Operating Margin
* Net Profit Margin
* Return on Equity (ROE)
* Return on Capital Employed (ROCE)

#### Risk

* Debt-to-Equity Ratio

These metrics help evaluate the company's operational efficiency, profitability, capital utilization and financial risk.

### 4. Valuation

A peer-comparison section containing:

| Company |    EPS | P/E Ratio |
| ------- | -----: | --------: |
| Infosys | ₹16.14 |     18.0x |
| TCS     | ₹37.92 |     17.8x |
| Wipro   | ₹12.60 |     15.2x |

The peer data is used to understand relative valuation using the **Price-to-Earnings (P/E) multiple**.
